Starfield 1943 — Birthday Edition
===================================

QUICK START
-----------
Open index.html in any browser. It detects your device and
guides you to the right version. On GitHub Pages, this file
loads automatically when someone visits the site URL.

HOSTING ON GITHUB PAGES (free, no account needed for recipient)
---------------------------------------------------------------
1. Create a free account at https://github.com
2. Create a new repository, e.g. "starfield-1943"
3. Upload all four HTML files to the repository
4. Go to Settings > Pages > Source: Deploy from branch > main / root
5. GitHub gives you a URL like:
      https://yourusername.github.io/starfield-1943/
6. Send Dad that link — it works on any device, any browser.
   No app to install, no login required.


VIEWING ON TV
-------------
See the TV guide section at the bottom of index.html for
step-by-step instructions covering:
  A. Chromecast / Google TV (easiest)
  B. Android screen mirror (Smart View)
  C. iPhone / iPad AirPlay
  D. Laptop + HDMI cable
Tip: Dad Mode has the largest text and reads well from a sofa.
